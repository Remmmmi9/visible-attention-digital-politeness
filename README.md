# Visible Attention — Freeform Postcard Archive

This version is built around:
- a freeform draggable postcard homepage
- integrated primary navigation with dropdown secondary navigation
- separate pages for secondary sections
- Morandi / archive / editorial feeling

Open `index.html` with VS Code Live Server.
Double-click a postcard or press Enter while focused to open its story.
